Puesto que los ejercicios ya han sido abordados, daré una explicación general sobre los temas comunes en la solución:
Usamos ArrayLists para guardar los objetos en listas. Esto nos permite generar y almacenar muchos objetos sin tener que crearlos uno por uno.
Implementamos Excepciones Personalizadas (mensajes de error propios) que se usan dentro de la estructura try-catch para manejar cualquier problema que pueda surgir.
También trabajamos con Herencia (una clase obtiene propiedades de otra), Clases Abstractas y Métodos Abstractos, lo que es fundamental para aplicar el Polimorfismo.
Tambien aplicamos los UML de los codigos que es una forma estandarizada de dibujar el diseño de un software para que todos lo entiendan sin leer el código completo.
